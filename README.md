## 🌌 درباره پروژه

مدل‌های زبانی بزرگ (LLMs) می‌توانند متن تولید کنند، به پرسش‌ها پاسخ دهند و اطلاعات را تحلیل کنند؛ اما آیا به‌تنهایی می‌توانند به پایگاه داده متصل شوند، اطلاعات یک سامانه را بررسی کنند یا عملیاتی را در یک نرم‌افزار انجام دهند؟

پاسخ این پرسش، ما را به یکی از موضوعات مهم دنیای هوش مصنوعی می‌رساند: **Model Context Protocol (MCP)**.

این پروژه یک ارائه دانشگاهی تعاملی و مبتنی بر وب است که با رویکردی مرحله‌به‌مرحله توضیح می‌دهد:

- مدل‌های زبانی چگونه متن تولید می‌کنند؟
- چرا دانش یک مدل به‌تنهایی برای تعامل با دنیای واقعی کافی نیست؟
- مفهوم Tool Calling چیست و چه تفاوتی با اجرای واقعی یک عملیات دارد؟
- پروتکل MCP چگونه ارتباط میان برنامه‌های هوش مصنوعی و ابزارها یا منابع خارجی را استاندارد می‌کند؟
- اجزای اصلی معماری MCP چگونه با یکدیگر ارتباط برقرار می‌کنند؟
- MCP چه تفاوتی با APIها و روش‌های سنتی یکپارچه‌سازی نرم‌افزارها دارد؟

هدف این پروژه صرفاً نمایش اسلایدها نیست؛ بلکه ایجاد یک **تجربه یادگیری و کشف تعاملی** است. مخاطب در طول ارائه، علاوه بر مطالعه توضیحات، با نمودارها، شبیه‌سازی‌ها، سناریوهای عملی و یادداشت‌های تفصیلی سخنران همراه می‌شود.

> 💡 **زبان ارائه:** محتوای آموزشی و یادداشت‌های سخنران عمدتاً فارسی هستند. رابط کاربری از چینش راست‌به‌چپ (RTL) پشتیبانی می‌کند و برای کدها، نام متدها و شناسه‌های فنی، نمایش چپ‌به‌راست (LTR) در نظر گرفته شده است.

## 🎯 هدف آموزشی

در پایان این ارائه، مخاطب باید بتواند:

- با سازوکار کلی تولید متن در مدل‌های زبانی و مفهوم پیش‌بینی Token آشنا شود.
- تفاوت میان دانش آموخته‌شده مدل و اطلاعاتی که هنگام اجرا در اختیار آن قرار می‌گیرد را درک کند.
- دلیل نیاز برنامه‌های هوش مصنوعی به ابزارها و منابع اطلاعاتی خارجی را توضیح دهد.
- مفهوم Tool Calling را بشناسد و درخواست مدل برای استفاده از ابزار را از اجرای واقعی آن تفکیک کند.
- نقش سه جزء اصلی **Host، MCP Client و MCP Server** را تشخیص دهد.
- تفاوت میان قابلیت‌های **Tools، Resources و Prompts** را توضیح دهد.
- با ساختار پیام‌های JSON-RPC و مفهوم Capability Discovery آشنا شود.
- کاربرد و تفاوت دو روش ارتباطی **STDIO و Streamable HTTP** را درک کند.
- ارتباط MCP با APIهای موجود و روش‌های سنتی یکپارچه‌سازی را توضیح دهد.
- مفاهیم امنیتی مانند مرزبندی دسترسی، اصل حداقل سطح دسترسی (Least Privilege) و تأیید انسانی را بشناسد.
- کاربردهای عملی، محدودیت‌ها و مسیر توسعه MCP را بررسی کند.

## 🏗️ معماری MCP در این ارائه

یکی از مهم‌ترین بخش‌های ارائه، شناخت نقش اجزای مختلف در یک برنامه مجهز به MCP است.

در این پروژه تلاش شده است مرز مسئولیت هر جزء به‌صورت دقیق و قابل‌فهم توضیح داده شود.

| جزء                 | مسئولیت                                                                                                                          |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Host**            | برنامه اصلی که تعامل با مدل، مدیریت Context و سیاست‌های دسترسی را هماهنگ می‌کند.                                                 |
| **MCP Client**      | بخش پروتکلی تحت مدیریت Host که با MCP Server متناظر ارتباط برقرار می‌کند.                                                        |
| **MCP Server**      | برنامه‌ای که قابلیت‌هایی مانند Tools، Resources و Prompts را در اختیار MCP Client قرار می‌دهد.                                   |
| **External System** | سامانه یا سرویس زیربنایی که Server ممکن است برای انجام وظایف خود از آن استفاده کند؛ مانند API، پایگاه داده یا یک نرم‌افزار دیگر. |

### یک نکته مهم درباره MCP

وقتی مدل زبانی درخواست استفاده از یک ابزار را تولید می‌کند، به این معنی نیست که عملیات موردنظر مستقیماً توسط خود مدل اجرا شده است.

درخواست مدل باید توسط اجزای برنامه دریافت و مدیریت شود. Host و سایر اجزای مرتبط، با توجه به طراحی و سیاست‌های امنیتی برنامه، مسئولیت هماهنگی، اعتبارسنجی، مجوزدهی و اجرای عملیات را بر عهده دارند.

**MCP یک استاندارد ارتباطی است؛ نه جایگزین تمام APIها و نه تضمینی خودکار برای امنیت سامانه‌ها.**

## 🚀 راه‌اندازی پروژه

اگر قصد دارید پروژه را به‌صورت محلی اجرا کنید یا در توسعه آن مشارکت داشته باشید، مراحل زیر را دنبال کنید.

### پیش‌نیازها

قبل از شروع، موارد زیر را نصب داشته باشید:

- [Node.js](https://nodejs.org/) سازگار با نسخه Next.js پروژه
- [npm](https://www.npmjs.com/)
- [Git](https://git-scm.com/)

### ۱. دریافت پروژه

```bash
git clone <repository-url>
cd MCP-Presentation
```

### ۲. نصب وابستگی‌ها

```bash
npm install
```

### ۳. اجرای محیط توسعه

```bash
npm run dev
```

حالا مرورگر خود را باز کنید و به آدرس زیر بروید:

[http://localhost:3000](http://localhost:3000)

### ۴. ساخت نسخه نهایی

```bash
npm run build
```

### ۵. اجرای نسخه نهایی

```bash
npm run start
```

> دستورات بالا بر اساس گردش کار مبتنی بر npm نوشته شده‌اند. برای مشاهده فهرست دقیق اسکریپت‌های قابل اجرا، فایل `package.json` پروژه را بررسی کنید.

## ⚠️ محدوده پروژه و ملاحظات آموزشی

برای درک صحیح هدف پروژه، توجه به چند نکته ضروری است:

- این پروژه یک ارائه آموزشی است و **پیاده‌سازی عملیاتی یک MCP Host، MCP Client یا MCP Server محسوب نمی‌شود.**
- سناریوهای مربوط به انبار، موجودی، خرید و امنیت از داده‌های نمونه استفاده می‌کنند.
- نتایج نمایش‌داده‌شده در شبیه‌سازها، پاسخ زنده API یا عملیات واقعی تجاری نیستند.
- محتوای اصلی ارائه فارسی است؛ اما اصطلاحات تخصصی و شناسه‌های پروتکل در موارد لازم به زبان انگلیسی حفظ شده‌اند.
- این ارائه مفاهیم MCP و بخشی از رفتار پروتکل را آموزش می‌دهد و جایگزین مستندات رسمی آن نیست.

برای مطالعه جزئیات هنجاری پروتکل و دنبال کردن آخرین تغییرات، به مستندات رسمی مراجعه کنید:

[**مستندات رسمی Model Context Protocol**](https://modelcontextprotocol.io/)
