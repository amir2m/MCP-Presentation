## ✨ درباره‌ی پروژه

این پروژه یک ارائه‌ی دانشگاهی تعاملی درباره‌ی **مدل‌های زبانی بزرگ (LLMs)**
و **Model Context Protocol (MCP)** است که به‌جای قالب مرسوم اسلایدها، در
قالب یک تجربه‌ی وب طراحی شده است.

مسیر آموزشی از مبانی تولید پاسخ توسط مدل زبانی آغاز می‌شود، به محدودیت‌های
مدل در دسترسی به اطلاعات و ابزارهای خارجی می‌رسد و سپس نشان می‌دهد MCP
چگونه می‌تواند ارتباط میان برنامه‌های هوش مصنوعی و سیستم‌های بیرونی را
استانداردتر کند.

هدف فقط معرفی چند اصطلاح فنی نیست؛ هدف، ساختن یک تصویر ذهنی روشن از
مسئله، راه‌حل و معماری پشت این فناوری‌هاست.

> **از «مدل چه می‌داند؟» تا «مدل چگونه می‌تواند از ابزارها استفاده کند؟»**

## 🎯 تجربه‌ی ارائه

این وب‌اپ برای دو شیوه‌ی استفاده طراحی شده است:

| حالت                  | کاربرد                                         |
|:----------------------|:-----------------------------------------------|
| **Presentation Mode** | نمایش مرحله‌به‌مرحله و متمرکز، مناسب ارائه‌ی زنده |
| **Scroll Mode**       | مرور پیوسته‌ی فصل‌ها و مطالعه با اسکرول          |

در طراحی تجربه تلاش شده است مفاهیم فنی با ترکیبی از دیاگرام‌ها،
شبیه‌سازی‌های آموزشی، تعاملات کنترل‌شده و حرکت‌های بصری ملایم توضیح داده
شوند.

## 🧭 نقشه‌ی یادگیری

ارائه در هفت فصل سازمان‌دهی شده است تا مخاطب از مفاهیم پایه به درک معماری
و کاربرد MCP برسد.

| فصل | موضوع                                                           | وضعیت               |

## 🧩 چه چیزهایی در این ارائه می‌بینید؟

- **مفاهیم، نه صرفاً تعریف‌ها:** توضیح تفاوت دانش آموزشی مدل و اطلاعات در
  دسترس هنگام اجرا (Runtime Context).
- **مرز مدل و محیط اجرا:** تفکیک مسئولیت مدل زبانی، برنامه‌ی میزبان
  (Host) و ابزارهای خارجی.
- **شبیه‌سازی آموزشی:** مشاهده‌ی ساده‌شده‌ی روند تولید پاسخ و فراخوانی
  ابزار.
- **مقایسه‌ی مفهومی:** درک مسئله‌ی اتصال‌های اختصاصی و ایده‌ی یک استاندارد
  مشترک.
- **تعامل هدفمند:** آزمون‌ها، کنترل‌های نمایشی و نمودارهای قابل‌درک.
- **طراحی واکنش‌گرا:** تجربه‌ی قابل استفاده در دسکتاپ، تبلت و موبایل.

> ⚠️ شبیه‌سازی‌های آموزشی برای توضیح مفاهیم طراحی شده‌اند و لزوماً اجرای
> واقعی یک مدل زبانی یا اتصال زنده به یک MCP Server نیستند؛ مگر آن‌که در
> همان بخش صریحاً خلاف آن مشخص شده باشد.

## 🚀 اجرای پروژه در سیستم شخصی

### پیش‌نیازها

- [Node.js](https://nodejs.org/) نسخه‌ی سازگار با پروژه
- npm
- Git

### نصب و اجرا

``` bash
# دریافت پروژه
git clone <YOUR_REPOSITORY_URL>

# ورود به پوشه‌ی پروژه
cd mcp-presentation

# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه
npm run dev
```

سپس آدرس زیر را در مرورگر باز کنید:

``` text
http://localhost:3000
```

### ساخت نسخه‌ی Production

``` bash
npm run build
```

> نام اسکریپت‌ها و نسخه‌ی Node.js را در `package.json` پروژه بررسی کنید؛
> دستورات بالا بر اساس ساختار رایج پروژه‌های Next.js نوشته شده‌اند.
